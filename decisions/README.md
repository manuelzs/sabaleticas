# Decisions

A running log of meaningful decisions: what we chose, why, what we expected, and
later — what actually happened. This is how we get better over time instead of
re-litigating the same calls.

## Format

Each decision is a dated entry:

```
## YYYY-MM-DD — Short title
**Decision:** what we're doing
**Why:** the reasoning and the numbers behind it
**Expected outcome:** what we think will happen
**Revisit:** when/under what condition we check back
**Outcome:** (filled in later) what actually happened
```

## Log

## 2026-05-21 — Validate with on-farm trials, don't trust borrowed studies
**Decision:** Treat published Colombian research as *hypotheses to test locally*, not
settled fact. As the operation matures (weighing + records), invest in running our own
controlled on-farm experiments to get region-specific numbers for Sabaleticas.
**Why:** Colombian ag studies are thin and vary by region (most figures in our research
library are Orinoquía/Brazilian/single-operation proxies, explicitly flagged). What's
true in Córdoba or the Llanos may not hold in the Cauca valley. The farm itself is the
only data source that's actually about *this* operation.
**Expected outcome:** Over time, a set of trial results (supplement response, grazing
systems, forage performance) that we trust because we measured them here.
**Revisit:** Once weighing is routine and we have a few finishing lotes — start with a
small, costed finishing-supplement trial (see [`../experiments/`](../experiments/)).
**Outcome:** _(pending)_
