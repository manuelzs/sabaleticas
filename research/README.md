# Research library

The knowledge base Manuel hasn't had time to read — Colombian literature, studies,
trade publications, and benchmarks on running a profitable cattle operation. Built
to **grow and stay traceable**: every claim cites a source, every source is registered.

## How it works

- **[`sources.md`](sources.md)** — the master source register. Every source has a stable
  ID (`S1`, `S2`, …) with full citation, type, region, date accessed, and a reliability
  tag. **Cite sources by `[S#]`** everywhere else. Add new sources with the next ID.
- **[`colombia-cattle-profitability.md`](colombia-cattle-profitability.md)** — the
  **overview**: 5 highest-leverage takeaways, glossary, standing caveats, and the index
  into the topic docs. Start here.
- **[`topics/`](topics/)** — **living per-subject documents**. New findings accrete into
  the right topic doc (not a new file each time), each with `[S#]` citations and an
  "open questions to research" list.

## Conventions

- Cite as `[S#]`; if a fact has no source yet, mark it `[unsourced]` so it's visible.
- **Never invent statistics.** If a Colombian figure can't be found, say so. Label
  regional proxies (e.g. Brazilian, Orinoquía) as such.
- Note dates on price/market figures — they drift; relationships are more durable.
